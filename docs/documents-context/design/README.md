# Arayüz tasarım kaynakları

- `tokens.css`: tasarım referansındaki renk ve ölçüler.
- `ikonlar/`, `desenler/`: görsel varlıklar.
- `harita/`: harita stili ve ilgili dosyalar.
- `ekranlar-15ekim/`: 15 Ekim ekran tasarımları.
- [Karşılaştırma notları](karsilastirma/KARSILASTIRMA.md): tasarım ile uygulamanın tarihli karşılaştırması.
- `ilk-prototip-…/`: eski prototipin kaynakları; referans amacıyla korunur.

Güncel kapsam için [frontend/backend notlarını](../FRONTEND_BACKEND_NOTLARI.md), prototipten çıkarılan dersler için [ilgili belgeyi](../PROTOTIP_DERSLERI.md) okuyun. Eserlerin 3D kaynakları [eserler](../eserler/README.md) altındadır.
