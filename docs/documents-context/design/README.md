# Arayüz tasarım kaynakları

Uygulanan tasarım `apps/web` içindedir: tema `apps/web/src/app/design.css`, token'lar `packages/design-tokens`. Bu klasör kaynak varlıkları ve tarihli referansları tutar.

- `ikonlar/`, `desenler/`: görsel varlıklar.
- `harita/`: uygulanmamış stil denemesi (`akar-style-cam.json`). Üründeki stiller `apps/web/public/harita/akar-style.json` ve `akar-style-gece.json`.
- `logo/`: logonun kaynak dosyaları; web boyutları `apps/web/public/logo/`.
- Kaldırılan prototip, 15 Ekim ekranları ve karşılaştırma notları Git geçmişindedir (2 Kasım 2026 temizliği, bkz. [Klasör yapısı](../KLASOR_YAPISI.md)).

Güncel kapsam için [frontend/backend notlarını](../FRONTEND_BACKEND_NOTLARI.md), prototipten çıkarılan dersler için [ilgili belgeyi](../PROTOTIP_DERSLERI.md) okuyun. Eserlerin 3D kaynakları [eserler](../eserler/README.md) altındadır.
