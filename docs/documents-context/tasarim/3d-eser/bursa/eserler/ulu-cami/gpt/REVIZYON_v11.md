# GPT v11 — kapı ve minare üst renkleri

Ana kapı ve iki yan kapı #795036 kahverengi ahşap tonuna çevrildi. Kapı panelleri aynı malzemeyi kullanıyor; pencere demirleri yeşil kaldı.
