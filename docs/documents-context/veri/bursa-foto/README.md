# Bursa fotoğraf arşivi (küçültülmüş)

Kaynak: `../vakıf-eserleri-envanteri/*.zip` (21 parça, Google Drive dışa aktarımı, toplam ~44 GB).
Disk yetmediği için fotoğraflar açılırken **uzun kenarı 2400 px'e küçültüldü** (JPEG q85). Orijinaller zip'lerde duruyor.

- Klasör yapısı kitabın bölümlerini izler: cilt → bölüm klasörü (`Links` ara klasörü kaldırıldı).
- Açılmayanlar: `.pdf` (6,5 GB sayfa taslakları), `.psd`, `.indd`, `.ai`, `.idml` (InDesign dosyaları).
- `_manifest.csv`: her dosya için orijinal zip, zip içi yol, orijinal boyut/piksel.
- Dosya adları çoğunlukla kamera/dron numarası (`DJI_…`, `ERD…`); eser adı içermez. Eser eşlemesi klasör düzeyinde yapılır.
- Toplam: 1975 fotoğraf, 0 hata.
